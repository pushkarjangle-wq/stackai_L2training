# Weather Intelligence App

Weather Intelligence application created with Google AI Studio and deployed to Cloudflare Pages.

## Data Sources
- Open-Meteo Geocoding API: https://geocoding-api.open-meteo.com/v1/search
- Open-Meteo Forecast API: https://api.open-meteo.com/v1/forecast

## Google AI Studio to GitHub
- Created application source in Google AI Studio App Build.
- Connected directly to GitHub repository `stackai_l2training`.

## Cloudflare Pages Deployment Instructions
- Framework preset: Vite
- Build command: npm run build
- Build output directory: dist
